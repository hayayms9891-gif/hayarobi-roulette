# 명절 용돈 룰렛 🎀

AI Community Lab **Hayarobi** — 설날·추석 용돈 뽑기 룰렛

링크만 열면 누구나 바로 돌립니다. 횟수 제한이 없어서 폰 하나를 돌려가며 써도 되고, 각자 자기 폰으로 열어도 됩니다. 나온 금액을 어른께 보여드리면 현금으로 받는 구조입니다.

## 규칙

12칸 — **꽝 · 1천 · 5천 · 1만 · 2만 · 5만** 각 2칸.

**보이는 칸 크기가 곧 확률입니다.** 고액일수록 좁게 그렸고, 그 좁은 만큼 실제로 덜 나옵니다.

| 금액 | 차지한 각도 | 확률 |
|---|---:|---:|
| 꽝 | 93.0° | 25.83% |
| 1,000원 | 81.0° | 22.50% |
| 5,000원 | 69.0° | 19.17% |
| 10,000원 | 57.0° | 15.83% |
| 20,000원 | 37.2° | 10.33% |
| 50,000원 | 22.8° | **6.33%** |

1인당 기댓값 **8,000원**, 5만원은 **16명 중 1명**꼴입니다. (200만 회 시뮬레이션으로 검증)

## 만든 방식

의존성 없는 HTML 파일 하나입니다. 빌드 과정도, 서버도, 외부 음원 파일도 없습니다.

| 기능 | 구현 |
|---|---|
| 룰렛 | SVG를 자바스크립트로 생성 |
| 회전 | `requestAnimationFrame` + easeOutQuart |
| 효과음 | Web Audio API로 직접 합성 |
| 폭죽 | Canvas에 이모지 렌더링 |
| 난수 | `crypto.getRandomValues` (모듈로 편향 제거) |

## 코드에서 볼 만한 곳

`index.html` 한 파일 안에 주석과 함께 정리해 뒀습니다.

- **각도로 뽑기** — `pickSlot()`. 칸 번호를 고르는 대신 원판 위 각도를 균등하게 찍습니다. 그러면 확률이 칸 넓이와 저절로 같아지고, 나머지 연산을 안 쓰니 모듈로 편향도 생기지 않습니다
- **아슬아슬한 멈춤** — `spinTo()`. 별도 연출 없이, 멈출 자리를 "칸에 막 들어선 지점"으로 잡아 감속 끝자락에 경계선을 느리게 넘게 했습니다
- **이어서 굴리기** — `currentRot`. 매번 0도로 되돌리면 다음 사람이 누를 때 원판이 순간이동합니다
- **셀렉터 충돌** — 휠과 바늘을 `.stage svg`로 묶으면 바늘이 휠 크기가 됩니다

## 파일

| 파일 | 용도 |

| `index.html` | 게임 전체 (HTML·CSS·JS 한 파일) |

| `hayarobi.webp` | 하야로비 로고 (1254×1254, 178KB) |

## 실행

두 파일을 같은 폴더에 두고 `index.html`을 브라우저로 열면 됩니다.
