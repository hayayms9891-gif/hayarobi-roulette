# 명절 용돈 룰렛 🎀

AI Community Lab **Hayarobi** — 설날·추석 용돈 뽑기 룰렛

링크를 받은 사람이 각자 휴대폰에서 **딱 한 번** 돌립니다. 나온 금액을 어른께 보여드리면 현금으로 받는 구조입니다.

## 규칙

- 12칸 — **꽝 · 1천 · 5천 · 1만 · 2만 · 5만** 각 2칸
- 모든 칸의 당첨 확률은 **똑같이 1/12**
- 고액 칸은 **좁게 그려서** 아슬아슬해 보이게 했을 뿐, 확률과는 무관합니다
- 1인당 기댓값 **14,333원**, 5만원은 6명 중 1명꼴

## 만든 방식

의존성 없는 HTML 파일 하나입니다. 빌드 과정도, 서버도, 외부 음원 파일도 없습니다.

| 기능 | 구현 |
|---|---|
| 룰렛 | SVG를 자바스크립트로 생성 |
| 회전 | `requestAnimationFrame` + easeOutQuart |
| 효과음 | Web Audio API로 직접 합성 |
| 폭죽 | Canvas에 이모지 렌더링 |
| 1회 제한 | `localStorage` |
| 난수 | `crypto.getRandomValues` (모듈로 편향 제거) |

## 코드에서 볼 만한 곳

`index.html` 한 파일 안에 주석과 함께 정리해 뒀습니다.

- **모듈로 편향 제거** — `randomBelow()`. 2³²을 12로 나눈 나머지를 그냥 쓰면 앞번호가 미세하게 자주 나옵니다
- **아슬아슬한 멈춤** — `spinTo()`. 별도 연출 없이, 멈출 자리를 "칸에 막 들어선 지점"으로 잡아 감속 끝자락에 경계선을 느리게 넘게 했습니다
- **새로고침 방지** — 결과를 정한 즉시 저장한 뒤 애니메이션을 시작합니다
- **셀렉터 충돌** — 휠과 바늘을 `.stage svg`로 묶으면 바늘이 휠 크기가 됩니다

## 실행

`index.html`을 브라우저로 열면 끝입니다.
