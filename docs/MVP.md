# MVP 정의

명절에 가족끼리 용돈을 뽑는 룰렛. **링크 하나로 끝나는 것**을 최소 조건으로 잡았다.

---

## 1. 누가, 어디서, 왜

| | |
|---|---|
| 쓰는 사람 | 용돈 받는 사람 본인 (아이일 수도, 아닐 수도) |
| 기기 | 각자 휴대폰 — 세로 화면 |
| 상황 | 설날·추석에 가족이 모인 자리 |
| 결과 | 나온 금액을 어른께 화면으로 보여주고 **실제 현금**을 받는다 |
| 전달 | 카톡으로 링크를 보낸다 |

## 2. MVP에 넣은 것

- 12칸 룰렛 — 꽝 · 1천 · 5천 · 1만 · 2만 · 5만 **각 2칸**
- 이름을 적고 돌리면 금액 + 축하 멘트
- 설날 / 추석 테마 전환
- 회전 연출 (약 5초, 끝에서 경계선을 아슬아슬하게 넘음)
- 돈봉투가 열리는 결과 연출, 폭죽, 효과음, 진동, 음소거
- QR 코드와 링크 복사
- 횟수 제한 없음 — 폰 하나를 돌려가며 써도 되고, 각자 열어도 된다

## 3. 일부러 뺀 것

여기가 MVP 정의의 핵심이다. **하고 싶었지만 안 한 것들과 그 이유.**

### 이미 나온 금액 제거

처음 요구사항에 있었다. 뽑힌 금액은 룰렛에서 빼서 12명이면 정확히 172,000원이 나가게 하는 방식이다.

> **뺀 이유**: 각자 다른 휴대폰에서 여는 구조라, 폰끼리 "누가 뭘 뽑았는지"를 공유할 방법이 없다. 서버나 공유 DB가 필요하고, 그건 "HTML 파일 하나, 링크 하나"라는 전제를 깬다.

두 요구사항이 동시에 성립하지 않는다는 걸 확인하고, **링크 배포 쪽을 남겼다.**

### 한 사람당 한 번 제한

`localStorage`로 구현해서 한동안 들어 있었다.

> **뺀 이유**: 시크릿 모드로 열면 뚫린다. 완전히 막으려면 사람마다 다른 링크와 서버가 필요하다. 어차피 어른이 옆에서 보고 현금을 주는 상황이라 **제한을 코드로 걸 실익이 없었다.** 대신 폰 하나를 돌려가며 쓰는 것도 자연스럽게 가능해졌다.

### 결과 기록·집계 화면

누가 얼마 받았는지 목록으로 보여주는 기능.

> **뺀 이유**: 위와 같다. 각자 폰에서 열면 한 곳에 모을 수단이 없다.

### 그 밖에

| 뺀 것 | 이유 |
|---|---|
| 참가자 명단·순서 정하기 | 링크를 받은 사람이 바로 돌리면 되므로 불필요 |
| 어른이 결과를 지정하는 비밀 모드 | 공정성이 이 게임의 재미라서 |
| 배경음악 | 명절엔 시끄러워서 안 들린다 |
| 금액 설정 화면 | 코드에 고정. 바꿀 일이 생기면 그때 배포한다 |
| 빌드 도구·프레임워크 | 파일 하나로 충분한 규모 |

## 4. 확정 스펙

| 항목 | 값 |
|---|---|
| 칸 수 | 12 (금액 6종 × 2칸) |
| 확률 | **그린 칸 넓이와 정확히 일치** |
| 5만원 확률 | 6.33% (16명 중 1명꼴) |
| 1인당 기댓값 | **8,000원** |
| 회전 시간 | 약 5.2초 |
| 의존성 | 없음 (구글 폰트만 외부) |
| 파일 | `index.html` 한 개 + 로고 이미지 |
| 배포 | GitHub Pages, push 후 약 50초 |

### 금액별 확률

| 금액 | 각도 | 확률 |
|---|---:|---:|
| 꽝 | 93.0° | 25.83% |
| 1,000원 | 81.0° | 22.50% |
| 5,000원 | 69.0° | 19.17% |
| 10,000원 | 57.0° | 15.83% |
| 20,000원 | 37.2° | 10.33% |
| 50,000원 | 22.8° | **6.33%** |

> 확률은 가중치 표가 아니라 **칸 넓이에서 자동으로 나온다.** `WIDTH` 값만 바꾸면 확률이 따라 움직인다.

## 5. 완료 기준

MVP가 끝났다고 보는 조건. 전부 실측으로 확인했다.

- [x] 링크를 받은 사람이 **로그인·설치 없이** 연다
- [x] 휴대폰에서 **스크롤 없이 한 화면**에 들어간다 (360×640 ~ 430×932 검증)
- [x] 바늘이 가리킨 칸과 표시 금액이 **항상 일치** (200만 회 시뮬레이션, 불일치 0건)
- [x] 실측 기댓값이 이론값과 일치 (8,006원 / 8,000원, 200만 회)
- [x] QR을 **실제로 스캔**하면 게임이 열린다 (4가지 크기 × 로고 유무 = 8경우 디코딩 성공)
- [x] 인터넷이 느려도 첫 터치에 효과음이 난다 (음원 파일 없이 합성)
