## 빠른 요약

### 규칙

12칸 — 꽝 · 1천 · 5천 · 1만 · 2만 · 5만 **각 2칸**.
**보이는 칸 크기가 곧 확률입니다.** 고액일수록 좁게 그렸고, 그 좁은 만큼 실제로 덜 나옵니다.

| 금액 | 각도 | 확률 |
|---|---:|---:|
| 꽝 | 93.0° | 25.83% |
| 1,000원 | 81.0° | 22.50% |
| 5,000원 | 69.0° | 19.17% |
| 10,000원 | 57.0° | 15.83% |
| 20,000원 | 37.2° | 10.33% |
| 50,000원 | 22.8° | **6.33%** |

1인당 기댓값 **8,000원**, 5만원은 **16명 중 1명**꼴. (200만 회 시뮬레이션 검증)

### 구현

| 기능 | 방식 |
|---|---|
| 룰렛 | SVG 부채꼴을 자바스크립트로 생성 |
| 회전 | `requestAnimationFrame` + `easeOutQuart` |
| 효과음 | Web Audio API로 파형 직접 합성 (음원 파일 없음) |
| 폭죽 | Canvas에 이모지 렌더링 |
| 봉투 | CSS 3D `rotateX` |
| 난수 | `crypto.getRandomValues` |
| 배포 | GitHub Pages |

### 코드에서 볼 만한 곳

`index.html` 한 파일 안에 주석과 함께 정리해 뒀습니다.

- **`pickSlot()`** — 칸 번호 대신 **각도**를 뽑습니다. 확률이 칸 넓이와 저절로 같아지고, 나머지 연산을 안 쓰니 모듈로 편향도 생기지 않습니다
- **`spinTo()`** — 아슬아슬한 멈춤을 따로 연출하지 않습니다. 멈출 자리를 "칸에 막 들어선 지점"으로 잡으면 감속 끝자락에 경계선을 저절로 기어서 넘습니다
- **`tone()`** — 게임의 모든 효과음이 이 함수 하나에서 나옵니다
- **셀렉터 충돌** — 휠과 바늘을 `.stage svg` 로 묶으면 바늘이 휠 크기가 됩니다. 실제로 한 번 당했습니다

### 배운 것

폰에서 화면이 안 채워지는 문제를 만났을 때, 눈에 띄게 빠진 `<!DOCTYPE html>` 을 보고 바로 원인이라 단정했습니다. 여러 개를 한꺼번에 고치니 증상이 사라져 맞는 줄 알았습니다.

**나중에 두 경우의 높이를 실제로 재보니 아니었습니다.** `compatMode` 는 갈리는데 레이아웃 높이는 같았습니다(413px / 413px). 진짜 원인은 `viewport` 메타 누락(980px 레이아웃 뷰포트)과 `justify-content` 부재였습니다.

> 그럴듯한 원인과 진짜 원인은 다를 수 있고, 그 차이는 재봐야만 드러납니다.
