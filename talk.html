pickSlot()

확률표를 만들지 않고, 각도를 뽑았습니다

칸마다 당첨 확률이 다른 룰렛을 만들 때 보통은 가중치 배열을 따로 둡니다. 그러면 그린 칸 크기와 실제 확률이 따로 놉니다. 화면엔 좁은데 잘 나오거나, 그 반대가 되기 쉽습니다.

대신 원판 위의 각도를 0~360도에서 균등하게 찍고, 그 각도가 어느 칸에 속하는지만 봤습니다. 확률이 칸 넓이와 저절로 같아지고, 관리할 표가 사라집니다. 

// 칸 번호를 뽑지 않는다. 각도를 뽑고 그 각도가 속한 칸을 준다.
function pickSlot(){
  const a = random01() * 360;
  for (const s of layout)
    if (a >= s.start && a < s.end) return s.index;
}

덤: 나머지 연산을 안 쓰니 crypto.getRandomValues() 의 모듈로 편향도 애초에 생기지 않습니다.

spinTo()

아슬아슬함은 연출이 아니라 좌표계에서 나옵니다

처음엔 3단계로 만들었습니다. 한 칸 지나친 곳까지 굴리고, 0.38초 완전히 멈추고, 다시 출발해 되돌아오기. 그런데 속도가 0이 됐다 다시 붙으니 누가 뒤에서 원판을 미는 것처럼 보였습니다.

고친 방법은 연출을 더 다듬는 게 아니라 멈출 자리를 옮기는 것이었습니다. 원판을 R도 돌리면 바늘이 가리키는 각도는 (360 − R) mod 360 이라, R이 커질수록 바늘은 칸의 오른쪽에서 들어와 왼쪽으로 빠집니다. 그래서 멈출 자리를 “칸에 막 들어선 지점”으로 잡으면, 감속이 끝나갈 때 남은 각도가 몇 도뿐이라 저절로 경계선을 기어서 넘습니다. 

// 멈출 자리 = 칸에 막 들어선 지점(안쪽 4~8도)
const settleIn = Math.min(seg.span * 0.45, 4 + Math.random() * 4);
const target   = seg.end - settleIn;
const finalRot = 360 * 7 + (360 - target);   // 일곱 바퀴 + 그 자리

// 감속은 곡선 하나뿐. 멈췄다 다시 미는 구간이 없다.
const rot = from + delta * easeOutQuart(e / T);

tone()

효과음은 파일이 아니라 파형입니다

mp3를 받지 않고 AudioContext 로 소리를 직접 만듭니다. 네트워크를 타지 않으니 시골집 느린 와이파이에서도 첫 터치에 바로 납니다. 게임 전체 효과음이 이 함수 하나에서 나옵니다. 

const tick    = () => tone(1180, 0.033, 'square', 0.07);
const fanfare = () => [523.25, 659.25, 783.99, 1046.5]  // 도미솔도
                     .forEach((f, i) => tone(f, 0.33, 'triangle', 0.2, i * 0.1));

딸깍 소리는 타이머가 아니라 매 프레임 바늘이 가리키는 칸이 바뀌었는지 보고 냅니다. 그래서 속도에 맞춰 저절로 느려지고, 끝에서는 경계를 넘는 순간 딱 한 번만 울립니다.

<!DOCTYPE html>

한 줄이 빠져서 레이아웃이 통째로 무너진 사건

폰에서 열어보니 내용이 위쪽 절반에만 몰리고 아래가 텅 비었습니다. 여백 설정을 아무리 만져도 그대로였습니다. 원인은 CSS가 아니었습니다.

이 파일은 원래 다른 게시 방식으로 만들어서 문서 골격을 시스템이 자동으로 붙여주고 있었고, GitHub Pages는 파일을 있는 그대로 내보내니 그게 통째로 빠진 채 나갔습니다. <!DOCTYPE html> 이 없으면 브라우저는 호환 모드(quirks mode) 로 읽고, 그러면 html, body 의 height:100% 가 풀립니다. 높이를 물려받을 기준이 사라지니 min-height:100% 도 0이 됩니다.

고치고 난 뒤엔 세 가지를 얹어 화면을 채웠습니다. 100dvh 는 카톡 내장 브라우저에서 주소창이 접혔다 펴져도 실제 보이는 높이를 따라가고, space-between 이 남는 세로 공간을 덩어리 사이로 나누고, vh 기반 clamp 가 폰 크기에 맞춰 룰렛을 키웁니다. 

.wrap{
  min-height: 100dvh;                  /* 주소창 접힘 대응 */
  justify-content: space-between;      /* 남는 공간 고르게 */
  gap: clamp(4px, 1.3vh, 20px);
}
.stage{ width: min(84vw, 40vh, 360px); }   /* 가로·세로 중 작은 쪽 */

실측: 360×640에서 룰렛 지름 234px, 430×932에서 360px. 모든 기종에서 스크롤 없음.
